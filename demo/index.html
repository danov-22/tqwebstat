The project

Built from a real operational need.

TQ Web Stat began as a practical internal tool for replacing scattered manual tracking with one focused workflow. The application uses Google Apps Script and Sheets, with authentication, activity history, exact undo, lead notes, admin notifications, and responsive reporting.

Product designFront-endApps ScriptGoogle Sheets
